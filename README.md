# Fingering Raurax Out

A pixel-art maze game. Steer her fingertip through the maze with the arrow keys or WASD
(swipe on touch screens). The finger grows as you go and retracts when you back up.
Reach the checkered exit to "finger things out" and move on to a bigger, freshly generated maze.

Keys: arrows / WASD move, R restarts the level, M mutes.

Run it by opening `index.html`, or serve the folder (`npx http-server`).
The pixel font is Press Start 2P (SIL OFL), bundled in `assets/`.
